Веб-платформа с вероятностным игровым движком (Roulette Simulation), безопасным хешированием учетных данных и двухфакторной аутентификацией (2FA) через Telegram-бота.

### Архитектурные особенности:
* **Двухфакторная верификация через Telegram:** Интеграция связки «Web + Telegram Bot» для отправки одноразовых кодов подтверждения (OTP) при входе в личный кабинет.
* **Криптографическая защита паролей:** Хеширование учетных данных пользователей в базе данных с использованием соли и стойких алгоритмов (Werkzeug Security).
* **Вероятностный игровой движок:** Математическая симуляция рулетки с динамическим контролем виртуального баланса, вейджер-логикой и историей ставок.
* **Облачное развертывание:** Адаптация веб-сервиса под работу в изолированной инфраструктуре PythonAnywhere.

### Стек технологий:
* Python 3.12
* Flask (Микросервисный веб-фреймворк)
* Werkzeug (Криптографическое хеширование)
* SQLite (Реляционная база данных пользователей и транзакций)
* Telegram Bot API (Канал доставки 2FA-кодов)
